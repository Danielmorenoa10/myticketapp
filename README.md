# Mitickets — Frontend React + Backend Express + MySQL

Proyecto SENA ADSO para gestión de tickets de soporte técnico.

## Stack
- React + Vite
- Node.js + Express
- MySQL
- JWT + bcryptjs

## Desarrollo

1. Configura MySQL y las variables de entorno del backend.
2. Ejecuta `npm install`.
3. Ejecuta `npm run seed` para cargar usuarios de prueba.
4. Ejecuta `npm run dev`.
5. Frontend: http://localhost:5173
6. API: http://localhost:3000

## Producción local

`npm run build` genera `frontend/dist`. El backend Express puede servir ese build.
